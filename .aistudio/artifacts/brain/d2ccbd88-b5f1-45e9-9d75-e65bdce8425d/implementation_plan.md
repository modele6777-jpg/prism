# [구현 완료] TTS 하이라이트 스마트스크롤 및 수동 조작 분리 연동 시스템

사용자가 TTS 음성 낭독을 들을 때, 현재 읽고 있는 **형광펜 하이라이트 문장을 시야의 중앙에 항상 자연스럽게 유지**해 주고, 사용자가 직접 마우스 휠이나 터치로 다른 내용을 탐색할 때 자동 스크롤과 충돌하지 않도록 **수동 조작을 똑똑하게 분리·감지(Smart Scroll)**하여 부드러운 화면 이동 경험을 제공합니다.

---

## 1. 확정된 사용자 요구사항 및 구현 완료 현황

1. **하이라이트 추적 위치**: 현재 낭독 중인 하이라이트 문장이 **스크롤 뷰포트의 정중앙(`block: 'center'`)**에 부드럽게 정렬되도록 오토 스크롤 구현 완료.
2. **스마트스크롤(수동 vs 자동 구분)**:
   - 사용자가 마우스 휠(`wheel`), 터치 드래그(`touchmove`), 키보드 스크롤(`keydown`), 스크롤바 조작 시 즉시 **수동 모드(User Override)**로 전환되어 오토 스크롤을 즉시 일시 정지.
   - 사용자 스크롤 중단 후 **3초 동안 추가 조작이 없으면** 다시 하이라이트 문장 위치로 자연스럽게 오토 스크롤 복귀.
   - 수동 모드 중 화면 하단에 세련된 **'낭독 위치로 이동(3s 후 자동 복귀)' 플로팅 버튼**(`SmartScrollResumeButton`)을 제공하여 원터치 즉시 복귀 지원.
3. **적용 범위**:
   - 🌟 **모달 창 전체**: 오늘의 데일리 타로 모달(`TodayTarotNarrationModal`)의 스크롤 컨테이너에 완벽 연동.
   - 🌟 **메인 전체 화면**: 일반 타로 결과 뷰, 사주✕타로 융합 오라클 3종 결과 뷰(`TrinityOracleSection`), 타임라인 연속 리딩 뷰 전반에 윈도우 스크롤러 및 플로팅 컨트롤러 연동 완료.
